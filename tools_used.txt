1. Primary Tools
Tool	Purpose	Command Examples
fcrackzip	Fast dictionary/brute-force attacks on traditional ZIP encryption	fcrackzip -u -D -p rockyou.txt file.zip
John the Ripper	Advanced cracking (supports AES encryption) via hash extraction	zip2john file.zip > hash.txt
john --wordlist=rockyou.txt hash.txt
Hashcat	GPU-accelerated cracking (for faster results with supported hardware)	hashcat -m 13600 hash.hc rockyou.txt
2. Support Tools
Tool	Purpose
zip2john	Extracts password hashes from ZIP files for John/Hashcat
unzip	Tests ZIP integrity/extracts files after cracking (unzip -P 'password' file.zip)
7z	Alternative extraction tool (handles some edge cases better than unzip)
